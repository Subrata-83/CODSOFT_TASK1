# CODSOFT Task 1 - Data Cleaning & Preprocessing

## 📌 Project Overview

This project is completed as part of the CodSoft Data Analytics Internship.

The objective of this task is to clean and preprocess a student performance dataset using Python and Pandas.

## 🛠️ Technologies Used

- Python
- Pandas
- OpenPyXL
- Microsoft Excel

## 📊 Dataset

The dataset contains student information such as:

- Student ID
- Name
- Gender
- Age
- Department
- Study Hours
- Attendance
- Math Score
- Reading Score
- Writing Score

The dataset contains 1005 records initially, including duplicate records and data-quality issues.

## 🧹 Data Cleaning Performed

The following preprocessing steps were performed:

1. Imported the Excel dataset using Pandas.
2. Inspected the dataset structure and column information.
3. Identified missing values.
4. Handled missing values using appropriate methods.
5. Identified and removed duplicate records.
6. Standardized inconsistent Gender values.
7. Standardized Department names.
8. Converted numeric columns into appropriate numeric data types.
9. Saved the cleaned dataset as a CSV file.

## ✅ Final Result

After cleaning:

- Missing values: 0
- Duplicate records: 0
- Cleaned records: 1000
- Numeric columns properly converted
- Categorical values standardized
